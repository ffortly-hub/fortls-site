Free browser tools

Fortran developer tools

All tools run locally in your browser. Nothing is sent to a server. Outputs are starting points: review them against the official documentation for your versions.

Advanced .fortls generator

Only options you enable are written. Leave blank to use fortls defaults. One path per line (or comma-separated).

fortls validator

Paste a config. Comments (JSONC) are accepted. Checks syntax, key names and value types against options known to this tool — not full semantics.

fpm.toml generator

Creates a starter manifest for the Fortran Package Manager.

VS Code settings generator

Creates settings for the Modern Fortran extension. Paste the result into .vscode/settings.json, merging with existing settings.

Config options change between releases; see the official fortls documentation and fpm documentation. Provided as-is without warranty (see Terms).
