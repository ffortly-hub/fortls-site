Frequently asked questions

What is fortls?

fortls is an open-source language server for Fortran. It gives editors features such as autocompletion, hover information and go-to-definition. The upstream project is developed by the fortran-lang community on GitHub. Read our plain-English guide.

Is FORTLS official?

No. FORTLS is an independent community resource. It is not the official fortls project and is not affiliated with the fortls maintainers or the Fortran-lang organization.

Which editors are supported?

Any editor with a Language Server Protocol client can use fortls, including Visual Studio Code (Modern Fortran extension), Neovim, Vim, Emacs and Sublime Text. See installing fortls in VS Code.

What is FPM?

The Fortran Package Manager (fpm) builds Fortran projects and manages dependencies. Our fpm.toml generator creates a starter manifest. Official documentation: fpm.fortran-lang.org.

What tools are available?

Four free browser tools: the .fortls generator, the fortls validator, the fpm.toml generator and the VS Code settings generator. They run locally and nothing is uploaded. Open the tools.

Is everything free?

Yes. The tools, guides and downloads are free. The site is kept running by voluntary support, labelled affiliate links (Cloudways and Vultr) and, in future, labelled sponsorships.

How can I support the project?

Through GitHub Sponsors, Ko-fi or PayPal on the support page, by subscribing to the newsletter, or by starring us on GitHub.

Can I advertise on FORTLS?

We offer a small number of manually managed, clearly labelled sponsorships. There are no display ads, popups or programmatic ad networks. See sponsors.
